iPhone & iPad

Use Safari · four quick steps

  1. Open the game in Safari

    Go to dumbluckgolf.com.

    Safari dumbluckgolf.com

  2. Tap Share

    Look for the square with an arrow pointing up. Depending on your Safari layout, Share may be inside the More (…) menu.

    Share

  3. Add to Home Screen

    Scroll through the actions and tap Add to Home Screen.

    ⊞   Add to Home Screen›

    If it’s missing, scroll to Edit Actions and add it.

  4. Confirm with Add

    Keep the name Dumb Luck Golf. If Open as Web App appears, leave it on, then tap Add.

    Open as Web App

Android

Use Chrome · four quick steps

  1. Open the game in Chrome

    Go to dumbluckgolf.com on your Android phone.

    Chrome dumbluckgolf.com

  2. Open the three-dot menu

    Tap More (⋮) beside the address bar.

    Chrome menu⋮

  3. Choose the install option

    Look for Install app or Install and create shortcut. Some versions say Add to Home screen.

    Install and create shortcut›

  4. Confirm the install

    Tap Install or Add and follow the on-screen prompts.

    Dumb Luck GolfInstall

You’re ready to tee it up.

Find the new icon on your Home Screen and tap it to play.

A couple of useful tips

I don’t see the Home Screen option.

Check that you’re using Safari on iPhone or Chrome on Android, outside another app’s built-in browser. Menu names and positions vary by browser version. On Android, look for the icon in your app drawer too.

Do I need the App Store?

No. This adds the browser game as a web app or Home Screen shortcut. Installation is free.

Will my account still work?

Yes. Sign in with your existing Dumb Luck Golf account if the Home Screen app asks you to log in again.
