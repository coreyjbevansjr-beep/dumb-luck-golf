# Dumb Luck Golfing

A retro pixel golf game playable at https://coreyjbevansjr-beep.github.io/dumb-luck-golf/.

## Controls

- Aim: Up/Down or mouse
- Face: Left/Right
- Clubs: Q/E or 1-4
- Swing: Space or click three times (start, power, accuracy)
- Mute: M
- Restart hole: R
- Title: Esc

The leaderboard uses Supabase.
